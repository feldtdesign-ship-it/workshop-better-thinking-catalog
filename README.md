# A Workshop for Better Thinking — Catalog

The full catalog, presented as a flipbook in a single self-contained HTML page.

**Live:** https://feldtdesign-ship-it.github.io/workshop-better-thinking-catalog/

## Files

- `index.html` — the whole flipbook. No build step, no dependencies. Open it in a browser.

Fonts (Archivo, Archivo Narrow, Archivo Black, IBM Plex Mono) load from Google Fonts,
so the page needs a network connection to look right.
